Welcome to my Kinyarwanda Voice Assistant project!✨
This is a basic speech-based assistant built to understand and respond to voice commands in Kinyarwanda. It's a small step toward making technology more accessible and inclusive for Kinyarwanda speakers.

💡 Features
🗣️ Listens to your voice in Kinyarwanda
🧠 Processes the command using basic logic
📢 Gives a verbal response back (in Kinyarwanda!)

🛠️ Tech Stack
Python 🐍
SpeechRecognition
pyttsx3 for text-to-speech

🚀 How to Use
Clone the repo
Install the dependencies
Run the script: python kinyawhisper.py

Speak and interact with your assistant in Kinyarwanda!

🎯 Goal
To help promote local language tech projects and make voice technology more reachable for Rwandans. This is just the beginning—and I’m learning and growing with every step ❤️
